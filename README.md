# ROB MEP Auto Hanger v0.3.7 — office menu update

[Download the complete updated tool ZIP](releases/ROB-MEP-Auto-Hanger-v0.3.7-baseline.zip?raw=true)

[Office walkthrough](releases/NEXT_TEST.md) | [Public-tool comparison](releases/PUBLIC_TOOL_COMPARISON.md)

The existing Auto Hanger menus are simplified for office review. Connection targets
shows compact beam/joist and deck groups with a clear steel-first/steel-only/deck-only
choice. Expand groups to review types. Custom types and role overrides sit under
Advanced structure options; saved nonstandard roles remain visible.

Hangers and placement shows only selected duct shapes and service-specific hanger
choices, spacing, rod limit, the unattached-draft option and Preview. Trapeze choices
appear when enabled. Advanced settings and support diagnostics start collapsed.
The main action says Preview layout, Place hangers or Run diagnostic test.

Preview remains on by default. Clearance defaults, individual rod measurement,
service isolation, station planning and rollback policy are preserved. The single-
hanger diagnostic remains optional and always removes its temporary hanger.

357 offline tests passed. Original archive and complete ZIP integrity verified.
Real Windows WPF rendering, menu-opening speed and retained IFC placement require
Revit 2025 validation; this is an office pilot build, not production certification.
